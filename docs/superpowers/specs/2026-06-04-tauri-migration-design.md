# Tauri Migration Design

**Date**: 2026-06-04
**Status**: draft
**Goal**: Replace Electron with Tauri v2 for faster builds and smaller bundle size.

## Motivation

Electron + electron-builder is slow: downloading Chromium + Node.js (~150MB), multi-step build (vite → tsc → electron-builder). The Vue frontend and Python backend don't need Chromium or Node.js at runtime — the OS-native WebView suffices.

Tauri v2 uses Edge WebView2 (built into Windows 10+) as the rendering engine and Rust for the native shell, cutting the bundle from ~150MB to ~5-10MB and build time from minutes to tens of seconds.

## Architecture (unchanged)

```
Tauri Shell (Rust) — replaces Electron main.ts
├─ spawns Python backend process (agentcore.exe)
├─ opens native WebView window loading Vue app
├─ provides menus (Restart Backend, Reload, Quit)
│
Vue 3 Frontend (unchanged) — runs inside WebView
├─ connects to backend via WebSocket ws://127.0.0.1:18765
│
Python Backend (unchanged) — agentcore.exe via PyInstaller
├─ WebSocket server on port 18765
```

Only the outer shell changes. The Vue frontend and Python backend are untouched.

## File Changes

### Removed

- `ui/electron/main.ts` — Electron main process (replaced by Tauri Rust)
- `ui/tsconfig.electron.json` — Electron TS compilation config

### Added

- `ui/src-tauri/Cargo.toml` — Rust dependencies (tauri v2, serde)
- `ui/src-tauri/src/main.rs` — Rust main (~80 lines)
- `ui/src-tauri/tauri.conf.json` — Tauri window/bundle config
- `ui/src-tauri/capabilities/default.json` — Tauri v2 permissions
- `ui/src-tauri/icons/` — app icon (generated by tauri init or placeholder)

### Modified

- `ui/package.json` — remove electron, electron-builder, concurrently, wait-on; add @tauri-apps/cli
- `build.bat` — replace `npm run electron:build` with `npm run tauri build`

### Unchanged

- `ui/src/**` — Vue components, styles, WebSocket client
- `ui/index.html` — entry HTML
- `ui/vite.config.ts` — Vite config
- `agentcore/**` — Python backend, tools, providers
- `agentcore.spec` — PyInstaller spec
- `config.yaml` — runtime config

## Tauri Rust Backend (src-tauri/src/main.rs)

Equivalent to `electron/main.ts`, handles:

1. **Python lifecycle** — spawn on startup, kill on exit, restart on menu action
   - Dev: `python main.py --ws --port 18765`
   - Prod: `{resource_dir}/agentcore/agentcore.exe --ws --port 18765`
2. **Window** — create WebviewWindow with title "AI Code Agent", 1200×800
   - Dev: load `http://localhost:5173`
   - Prod: load bundled `dist/index.html`
3. **Menu** — native menu bar
   - Agent → Restart Backend, Quit
   - View → Reload, Toggle DevTools
4. **Lifecycle** — kill Python process on window close / app exit

## Tauri Configuration (tauri.conf.json)

- `productName`: "AI Code Agent"
- `identifier`: "com.ai-codeagent.app"
- `build.frontendDist`: "../dist" (Vite output)
- `build.devUrl`: "http://localhost:5173"
- `app.windows[0]`: 1200×800, title "AI Code Agent"
- `bundle.resources`: `../build/agentcore/**` → `agentcore/` (bundles PyInstaller output)
- `bundle.targets`: "nsis" (Windows installer)

## Build Pipeline

```
build.bat:
  [1/2] pyinstaller agentcore.spec        → build/agentcore/agentcore.exe  (unchanged)
  [2/2] cd ui && npm run tauri build       → build/tauri-release/           (was electron:build)
```

## Risks & Mitigations

- **WebView2 availability**: Windows 10+ has it built in; Windows 7/8 would need the Evergreen installer. Acceptable — Windows 10+ is the target.
- **Rust toolchain**: User needs `rustup` + `cargo` installed. Added to prerequisites.
- **Tauri IPC not needed**: The Vue app communicates via WebSocket with the Python backend, not via Tauri IPC. The Rust side only manages the Python process and window — no IPC surface exposed.

## Prerequisites (new)

- Rust toolchain: `rustup` with MSVC target (Windows)
- Existing: Python 3.11+, Node.js 20+

## Migration Steps (summary)

1. Install Rust toolchain
2. Remove Electron files (`electron/main.ts`, `tsconfig.electron.json`)
3. Run `npm create tauri-app@latest` or manually scaffold `src-tauri/`
4. Write `main.rs` (Python process management + window + menu)
5. Update `package.json` and `build.bat`
6. Test: `npm run tauri dev` (dev mode), `cargo tauri build` (production)
